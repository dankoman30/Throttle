Known gaps & stand-ins

  • Kill switch (A3 / PA4): the part on hand is normally-open, which is backwards for this design. Bench testing bridges the two leads with a plain jumper wire instead. Must be swapped for a genuine normally-closed switch or contact block before this is wired for real — see docs/OPEN-ITEMS.md.
  • Handle battery power: onboard battery sensing was dropped entirely in favor of a standalone pack meter, but the board still needs an actual power source for field use, separate from bench power over USB. Pack chemistry/voltage is still open.
  • VIN: unconnected while bench-powered over USB. This board has no 5V need (no servo here) — 3V3 is the only logic/LED/pot rail in use.
  • PA2 (VCP_TX): the one uncommitted usable pin. Wired to the ST-Link virtual COM port by default — leave it alone unless USB serial debug is ever needed.
  • Trigger travel: real ADC min/max at full release/full pull hasn't been measured yet; the 0–4095 → 0–255 mapping still assumes full rail-to-rail range.
